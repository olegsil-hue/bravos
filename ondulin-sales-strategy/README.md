# Ондулин: пакет к встрече с ГД и HR

Рабочие материалы к отбору на **Директора по продажам**. Собраны под совет рекрутера: мотивация «большой → меньший бизнес», рынок, вопросы, упор на план / дистрибьюторов / команду, лидерство и отношения на 360°.

## С чего начать

1. **[meeting-playbook.md](meeting-playbook.md)** — читать накануне. Речь про мотивацию, как делиться экспертным мнением, банк вопросов, скрипты неудобных вопросов.
2. **[interview-cheat-sheet.md](interview-cheat-sheet.md)** — одна страница в телефон: цифры, сценарии, 6 вопросов ГД.
3. **[index.html](index.html)** — полный бриф: рынок, конкуренты, каналы, рычаги роста, 90/180/365. Открыть в браузере, можно печатать A4.

На саму онлайн-встречу в голову класть плейбук, не весь HTML. HTML — чтобы мнение опиралось на факты.

Цифры — открытые источники на сентябрь 2026. Сплиты кровля/плёнка/каналы внутри компании в отчётности не раскрыты: это гипотезы, их надо сверять, не защищать.

# Ондулин: пакет Олега Сильченко к встрече с ГД и HR

## Откройте это — презентация без PowerPoint

**Файл приложения:** [Ondulin-vstrecha.html](Ondulin-vstrecha.html)  
Двойной клик или перетащите в Chrome / Edge / Safari. Вверху вкладка **«Презентация»**. Стрелки ← → листают слайды, **F** — на весь экран.

**PDF, если нужен файл «как слайды»:** [Ondulin-tochki-rosta.pdf](Ondulin-tochki-rosta.pdf) — 12 слайдов, открывается в Preview / Acrobat / браузере.

PPTX часто не открывается без PowerPoint или из облака не доезжает. HTML и PDF — рабочие копии.

В приложении также весь этот чат в сжатом виде: о себе, точки роста, каверзные вопросы (включая уход из LG), 90/180/365, рынок.

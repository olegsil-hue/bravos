📋 Методика деления

🎯 Приоритеты деления

1️⃣ КЛЮЧЕВОЙ (Главный): Максимально равное количество игроков в каждой команде

→ Делить нацело не обязательно: остаток распределяется по одному игроку на команды
→ 9 игроков ÷ 2 команды = 5 + 4 игрока

2️⃣ ВТОРИЧНЫЙ (Баланс состава):

  • Каждой команде по 1 вратарю (профильный GK или со вторичной позицией GK), если вратари есть среди играющих — иначе команда помечается «⚠ Нет вратаря»
  • Максимум 3 игрока с одинаковым набором позиций (напр. DEF/MID)
  • ✅ Минимум 1 игрок с позицией ST, если такие игроки есть

3️⃣ ТРЕТИЧНЫЙ (Баланс рейтинга): команда с наименьшим текущим рейтингом получает игрока первой

🔄 Постобработка и ручная правка

Автоматически: проверка ST в каждой команде и обмены игроков для баланса рейтинга.

Вручную: на вкладке «Команды» результат можно перетащить мышкой — просто перетащите карточку игрока в другую команду, баланс и средние навыки пересчитаются сразу.

📅 Игровые дни

Игровой день = дата + составы команд + список отдельных мини-игр между парами команд в этот день (формат «проигравший уступает место»). По каждой мини-игре указывается счёт и, по желанию, кто забил. Итоговая таблица дня (И/В/Н/П/голы/очки, 3 очка за победу, 1 за ничью) считается автоматически, лучшая команда отмечается 🥇.

16 старых матчей, записанных ещё до этого формата, показаны отдельными карточками без турнирной таблицы (недостаточно данных о результатах между конкретными парами команд).

💾 Хранение данных

Список игроков и игровые дни сохраняются в этом браузере (localStorage). Для переноса на другое устройство используйте резервную копию (вкладка «Игроки»).

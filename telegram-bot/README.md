# Football Heroes — Telegram-бот

Еженедельный опрос → деление на команды → апрув. Использует ту же логику
деления и формулу рейтинга, что и `football-heroes-live.html` (см.
`src/core/`), но со своей базой SQLite вместо localStorage браузера — это
и есть общий источник данных, доступный боту.

**Реализовано сейчас:**
1. `/poll` (только админ) — публикует опрос «Футбол в среду в 19:00 (до 15
   человек)» с вариантами «Буду» / «Не смогу» в групповой чат.
2. Каждую **среду в 12:00** бот сам закрывает последний открытый опрос,
   делит проголосовавших «Буду» на 2 команды (≤10 человек) или 3 (11–15),
   и присылает состав вам в личку с кнопками «Утвердить» / «Пересчитать».
3. После утверждения состав сохраняется и объявляется в группе.

**Ещё не реализовано (следующий этап):** запись игр в среду с 18:00
(инлайн-выбор команд, гол/гол+пас, логика «проигравший выходит») и отправка
итоговых картинок по результатам дня — как у веб-приложения на вкладке
«Игровые дни».

## Деплой на Railway (рекомендованный вариант)

1. **Создайте бота**: в Telegram напишите **@BotFather** → `/newbot` →
   следуйте подсказкам → скопируйте токен вида `123456:ABC-...`.
2. **Узнайте свой Telegram user id**: напишите **@userinfobot** → он
   пришлёт ваш `id`.
3. **Добавьте бота в вашу группу** (ту, где будет идти опрос и запись игр),
   дайте ему право отправлять сообщения.
4. **Узнайте id группы**: отправьте в группу любое сообщение, затем
   откройте в браузере
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` и найдите
   `"chat":{"id": -100...}` — это отрицательное число, оно и есть
   `TELEGRAM_GROUP_CHAT_ID`.
5. **Railway**: зайдите на [railway.app](https://railway.app), заведите
   аккаунт (можно через GitHub), **New Project → Deploy from GitHub repo**,
   выберите этот репозиторий, укажите **Root Directory: `telegram-bot`**.
6. В настройках проекта на Railway откройте **Variables** и добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен из шага 1
   - `TELEGRAM_GROUP_CHAT_ID` — id из шага 4
   - `TELEGRAM_ADMIN_USER_ID` — ваш id из шага 2
   - `TIMEZONE` — `Europe/Moscow` (или другой, если нужно)
7. Добавьте **Volume** (Railway → Settings → Volumes), примонтируйте на
   путь `/app/data` — это постоянное хранилище для файла SQLite, чтобы
   данные не терялись при перезапуске. Переменную `DB_PATH` при этом можно
   не трогать (по умолчанию `./data/football.db`).
8. Railway сам подхватит `npm start` из `package.json` и запустит бота.
   В логах должно появиться `Бот запущен.`.

## Первое использование

1. Каждый игрок один раз пишет боту `/register Имя Фамилия` — ровно так,
   как имя записано в приложении (список: команда `/players`).
2. Вы (админ) отправляете боту в личке `/poll`, когда решите открыть запись
   на игру.
3. В среду в 12:00 бот сам всё посчитает и пришлёт вам состав на апрув.

## Локальный запуск для проверки

```bash
cd telegram-bot
npm install
cp .env.example .env   # заполните токен и id
npm start
```

## Синхронизация с веб-версией

`src/seed-data.json` — снимок ростера и истории игр на момент создания
бота (тот же, что в `football-heroes-live.html`). После первого запуска
бот хранит свою собственную копию в SQLite и дальше живёт независимо от
веб-версии — правки в одном месте не попадают в другое автоматически.
Если нужно наладить постоянную синхронизацию (например, чтобы бот и
веб-страница читали одну и ту же базу) — это отдельная следующая задача:
веб-часть тогда тоже должна переехать с localStorage на этот же бэкенд.
